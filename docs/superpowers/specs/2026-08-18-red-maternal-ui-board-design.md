# 红色母婴 UI 设计系统看板设计说明

## 目标

将现有蓝色 UI 看板改造成清晰、可编辑、可在线访问的红色母婴设计系统看板。默认色彩遵循《红色母婴小程序 UI 设计系统 Figma Make Guidelines》，用户可以直接修改关键色号并实时查看组件效果。

## 页面结构

页面保持单页双栏结构：左侧为颜色编辑区，右侧为设计系统预览区。桌面端固定显示编辑面板，移动端改为上下排列。整体使用暖灰页面背景、白色卡片和清晰的中文排版，不使用大面积红色渐变或装饰性光斑。

## 可编辑颜色

看板默认提供五个独立 Token：

- Brand Primary：`#D62F36`
- Price Red：`#F04438`
- Promo Red：`#FF4D4F`
- Member Dark Red：`#8F1D22`
- Care Pink：`#FF7A90`

每个 Token 同时支持系统取色器和十六进制文本输入。合法色号即时应用；非法输入在失焦时恢复当前值。修改结果保存在当前浏览器，重新打开页面后继续保留。用户可以恢复规范默认值，并一键复制 CSS 变量。

## 预览内容

预览区包含品牌主色色阶、字体层级、按钮状态、搜索输入、底部导航、价格与促销标签、会员权益、关怀提示和商品卡示例。不同业务语义使用各自 Token，避免所有红色元素共用品牌主色。

文字优先保证可读性：正文不小于 14px，辅助说明不小于 12px，色号使用等宽字体完整显示；主要文本使用 `#1F2329`，次级文本使用 `#646A73`。

## 交互与状态

- 修改任一色号后，相关组件实时更新。
- 复制成功后按钮显示短暂确认反馈。
- 恢复默认值仅重置颜色，不影响页面结构。
- 键盘用户可以访问全部输入和按钮，并获得清晰聚焦状态。
- 所有控件在移动端保持至少 44px 的主要触控区域。

## 数据与错误处理

看板不需要账号、数据库或外部数据。颜色偏好仅保存在浏览器本地。读取到损坏或不完整的本地数据时，页面回退到规范默认值，不阻断渲染。

## 验收标准

1. 首次打开时显示五个规范默认色号。
2. 修改每个 Token 都会更新对应的预览组件。
3. 刷新页面后保留有效修改，恢复默认功能可用。
4. CSS Token 可复制，且名称与当前色值一致。
5. 桌面和移动宽度下内容不溢出，文字清晰可辨。
6. 生产构建成功，并发布为可访问的私有在线链接。

## 实施范围

本次只改造现有单页看板及其样式、页面元信息和必要测试，不增加登录、多人协作、云端存储或多页面管理功能。
